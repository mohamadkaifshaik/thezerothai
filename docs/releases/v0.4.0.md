# Release notes: v0.4.0

Web release. Production moves from v0.1.0 (revision `api-00003-tiw`) to the build that contains the social graph, posts and
timelines, the account deletion/export lifecycle, and the modern dark UI. **Every new server flag ships OFF.**

## What users see at 100% traffic
- **Modern dark UI** for the feed, post card, profile and composer (web). Snackbar actions are legible in both themes.
- **Client-side account delete for accounts without a profile or with an unverified email** (L-5, accepted 2026-10-08):
  the app deletes the Firebase Auth user directly. This path is not behind a flag.
- Everything else new is behind a flag and invisible until it is turned on (below).

## Changes since v0.1.0
- Identity: verified-email rule on every RPC, `CreateProfile` checks that the Auth user still exists (M2), `deletionJob`
  fields on the profile, GetMe/GetProfile unchanged for existing users.
- Graph (ADR-0008/0009): follow, unfollow, block, mute, lists, purge.
- Posts and timeline (ADR-0010): create/delete, user and home timelines, read-budget interceptor (P0).
- Account lifecycle (ADR-0011): DeleteAccount, RequestAccountExport/GetAccountExport, `jobs` topic and push endpoint,
  daily maintenance backstop, C1-C4 controls.
- Infra already applied on 2026-10-09 (no apply in this release): exports bucket, `jobs` topic + DLQ, custom role, C4
  alert, 9 Firestore indexes. Ops alert policies are prod-only since #113 (dev destroyed 2026-10-10).

## Operations
- **Rollback:** `gcloud run services update-traffic api --project=dzeroth-prod --region=asia-south1 --to-revisions=api-00003-tiw=100`.
  Never `--to-latest`. Never route to `api-00004`..`api-00007` (Terraform-made, never smoke-tested). Web: Firebase
  Hosting rollback to the v0.1.0 release. See `docs/runbooks/rollback.md` (async/jobs caveats).
- **Not distributed:** the AAB/iOS artifacts `release-prod` builds. This is web-only (see readiness F14).
- **Runbooks:** `account-deletion.md` (manual path is the email-request path; T12 not built), `rollback.md`, `graph.md`, `posts.md`.
- **Readiness report:** `docs/reviews/release-v0.4.0-readiness.md`.

## Known limits
- On-device client delete (Google/Apple/password on mobile) and Apple token revocation are unverified.
- Export size ceiling per invocation is unmeasured (R1); oversize exports fail as `too_large` by design.
- `HashUID` in logs is an unkeyed truncated SHA-256 (F15).
- Error Reporting API is not enabled in prod; use Logs Explorer `severity>=ERROR` (F13).
