Build glue generated by `flutter_rust_bridge_codegen integrate` 2.13.0 (Cargokit), cut down to Android: during an
Android build, Gradle runs Cargokit, which compiles `../rust` (the `dzmls_flutter` crate) for each target ABI and
bundles `libdzmls_flutter.so`. See `crypto/README.md` ("Android") for what it needs and the local changes made to
the vendored Cargokit.
